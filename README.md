Calculadora Android - Jetpack Compose

Este repositório contém o código-fonte de um aplicativo de calculadora nativo para Android. O projeto foi desenvolvido como resolução de uma atividade prática, focando em uma interface moderna e no funcionamento preciso das operações matemáticas.

📱 Sobre o Projeto

O aplicativo oferece uma interface intuitiva em modo escuro (Dark Theme), projetada para facilitar a visualização. A tela é dividida para exibir o histórico do cálculo em andamento na parte superior e o resultado em destaque logo abaixo, seguindo princípios de design limpo e responsivo.

🚀 Funcionalidades

Operações Básicas: Soma (+), Subtração (-), Multiplicação (×) e Divisão (÷).
  Recursos Adicionais:
  * Cálculo de Porcentagem (%).
  * Alteração de Sinal (+/-).
  * Limpeza de Tela (C).
  Tratamento de Dados: Suporte a cálculos com números decimais e formatação automática para remover casas decimais desnecessárias quando o resultado for um número inteiro (ex: exibir `5` em vez de `5.0`).

🛠️ Tecnologias Utilizadas

Linguagem: Kotlin
Interface (UI): Jetpack Compose
Ambiente de Desenvolvimento: Android Studio
Arquitetura de UI: Componentes declarativos e gerenciamento de estado via `remember` e `mutableStateOf`.
